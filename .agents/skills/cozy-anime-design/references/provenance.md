# Approved reference provenance

Distilled from a DHMO design/implementation session in November 2026. The user approved both a playable HTML exploration and the final Compose implementation, then requested a reusable skill.

The brief asked for a cute hand-painted-anime / lo-fi-room feeling across an app, especially logging water and reaching goals. Approved ideas: an original leaf-hatted companion, drop/ripple/hop for successful logs, warm room/fireflies for the first daily goal, history garden without guilt, gentle paper notes, saved Day/Night choice and reduced motion.

The implementation brief to Astra stressed anticipation, squash/stretch, follow-through, damped settling, expressive eyes, leaf secondary motion, finite smooth fireflies, no replay on load/restoration/goal edits, and readable artwork at the actual 230 dp hero size. Feature logic tied cues to confirmed data and persisted the once-per-hydration-day marker.

Native implementation: commit `a576ec0`, PR https://github.com/capeterson/dihydrogen-monoxide/pull/31 . The playable HTML and selected source are bundled. Screenshots show disposable emulator demo quantities, not user health records. The water theme, character, layout and hydration-day boundary are examples, not mandates for new products.

The bundled HTML study's cleanup ownership was tightened during forward testing so an ordinary action no longer cancels an active milestone. Its explicit replay/reset controls remain demonstration tools, not production event rules. The original project preview was not changed by skill creation.

The DHMO launcher identity subsequently selected by the user is the flower-hatted
water spirit in a clear glass. Its approved master and reproducible Android
exports live at the repository's `artwork/launcher/`. The earlier leaf-hatted
scene studies remain useful motion references; consult the flower master when
working on this app's launcher identity.
